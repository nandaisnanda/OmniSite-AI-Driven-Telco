# Every compiled dependency below is pinned to a version publishing both cp313 and
# cp314 manylinux wheels. Streamlit Community Cloud now defaults to Python 3.14, and the

# geos-config, so the deployment never started. Check wheel coverage before lowering any
# of these, not just whether the version resolves.
#
# pandas deliberately stays on 2.x: 3.0 is a breaking release, and this only needs to
# clear the wheel bar. osmnx stays on 1.x for the same reason — 2.x moved the
# projection and nearest-edge APIs that the road-access engine calls.
